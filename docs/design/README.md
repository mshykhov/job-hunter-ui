# Product design

Living design documentation for the Job Hunter web application.

- [Product context](product.md) records verified users, routes, workflows, and constraints.
- [Design system](system.md) records the approved visual and interaction direction.
- [`design-system/`](../../design-system/README.md) contains the repository-owned token and component previews.

Update `product.md` when a user, route, workflow, permission, or platform constraint changes. Update `system.md`, `src/styles/theme.ts`, and `design-system/tokens.css` together when the approved visual system changes. Page-specific documents are needed only for intentional deviations from the shared system.
